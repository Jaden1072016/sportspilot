# SportsPilot

Independent NBA prediction and research app. Our own pregame and live win chances first, Polymarket prices second. Research only: no automatic trading.

- App: `app/` (Netlify base directory)
- Start here: `START_HERE.md`, then `docs/IMPLEMENTATION_BACKLOG.md`
- Model results: `docs/reports/`

## Deploy on Netlify
Import this repo, set **Base directory** to `app`, deploy. Build settings come from `app/netlify.toml`.
